> LAN-инструмент удалённого доступа для Windows.

Y.Desk создан для помощи пользователям и управления компьютерами в локальной сети. Первый выпуск имеет статус **Demo / pre-release** и предназначен для тестирования в доверенной сети.

## Демо-версия

| Что | Состояние |
| --- | --- |
| Установщик Windows | Доступен в Releases |
| Обновления | Пользователь сам решает, открывать ли страницу новой версии |
| Документация | В процессе развития |

## Возможности

- удалённое подключение к компьютерам в LAN;
- роли и разграничение прав доступа;
- интерактивный доступ с подтверждением на стороне агента;
- управляемая передача файлов с отдельной папкой обмена;
- понятные настройки для администратора и обычных пользователей;
- ярлыки рабочего стола для прямого подключения.

## Безопасность

Безопасность Y.Desk проработана на нескольких уровнях:

- TLS 1.2/1.3 шифрует канал связи между Viewer и Agent;
- Viewer запоминает и проверяет TLS-отпечаток агента, предупреждая о неожиданной смене сертификата;
- пароли не хранятся в открытом виде: используются PBKDF2-SHA256 и уникальная соль;
- ограничитель попыток входа временно блокирует подбор пароля;
- IP-фильтр ограничивает круг устройств, с которых возможны подключения;
- агент может требовать локального подтверждения каждого нового подключения;
- права доступа задаются отдельно для каждого пользователя: просмотр, управление, системные команды, сессии и передача файлов;
- для обычных пользователей файлы ограничены папкой обмена, а полный доступ выдаётся только явно назначенным администраторам;
- журнал безопасности фиксирует входы, отказы, блокировки и изменения учётных записей, не сохраняя пароли, содержимое буфера обмена или передаваемые файлы.

Удалённый доступ требует осторожности. Используйте демо-сборку только на компьютерах и в сетях, которыми вы вправе управлять. Не публикуйте найденные уязвимости в Issues — свяжитесь с владельцем репозитория напрямую через GitHub.
