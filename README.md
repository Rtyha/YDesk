# Y.Desk

> LAN-инструмент удалённого доступа для Windows — проект в активной разработке.

Y.Desk создаётся как независимое решение для помощи пользователям и управления компьютерами в локальной сети. Сейчас это **pre-release**: репозиторий открыт, чтобы постепенно показать путь разработки, но исходный код, установщики и демо-сборки ещё не опубликованы.

## Статус

| Что | Состояние |
| --- | --- |
| Исходный код | Готовится к публикации |
| Демо и установщики | Пока не выпущены |
| Релизы | Отсутствуют |
| Документация | В процессе |

## Направление проекта

- удалённое подключение к компьютерам в LAN;
- роли и разграничение прав доступа;
- интерактивный доступ с подтверждением на стороне агента;
- защищённый канал связи;
- управляемая передача файлов с отдельной папкой обмена;
- понятные настройки для администратора и обычных пользователей.

## Безопасность

Удалённый доступ требует осторожности. До первого стабильного релиза Y.Desk не следует использовать в критичной или производственной среде. Перед публикацией сборок планируются проверяемые обновления и подписи релизных артефактов.

Не публикуйте найденные уязвимости в Issues. Пока публичный канал для security-reporting не настроен — свяжитесь с владельцем репозитория напрямую через GitHub.
