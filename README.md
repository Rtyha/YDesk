> LAN-инструмент удалённого доступа для Windows.

Y.Desk создаётся как независимое решение для помощи пользователям и управления компьютерами в локальной сети. Первый выпуск имеет статус **Demo / pre-release**: он предназначен для тестирования в доверенной сети.

## Демо-версия

| Что | Состояние |
| --- | --- |
| Установщик Windows | Готовится к публикации |
| Автоматическая установка обновлений | Не используется |
| Проверка обновлений | Только уведомление и переход на GitHub Releases |
| Цифровая подпись | Пока отсутствует |
| Исходный код | Будет опубликован позднее |

## Возможности

- удалённое подключение к компьютерам в LAN;
- роли и разграничение прав доступа;
- интерактивный доступ с подтверждением на стороне агента;
- защищённый канал связи и проверка TLS-отпечатка;
- управляемая передача файлов с отдельной папкой обмена;
- понятные настройки для администратора и обычных пользователей;
- ярлыки рабочего стола для прямого подключения.

## Установка и обновления

Скачивайте установщик только из раздела [Releases](https://github.com/Rtyha/YDesk/releases) этого репозитория. Viewer никогда не скачивает и не устанавливает обновления сам: он может лишь сообщить о новой версии и открыть страницу релиза после подтверждения пользователя.

На этом этапе установщик не имеет цифровой подписи, поэтому Windows может показать предупреждение о неизвестном издателе. Перед запуском сверяйте SHA-256 из файла `SHA256SUMS.txt`, приложенного к релизу.

## Безопасность

Удалённый доступ требует осторожности. Не используйте демо-сборку в критичной или производственной среде. Не публикуйте найденные уязвимости в Issues — свяжитесь с владельцем репозитория напрямую через GitHub.
